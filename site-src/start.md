# Stoagen — assistant start page

This file is the front door for AI assistants. A person shared this link so
their assistant can learn what Stoagen is.

What Stoagen is: a system for building websites that people and their AI
assistants can both read faithfully. Every page is written once and
published twice: a readable human page, and a markdown mirror beside it
carrying the same content plus sources and caveats. Neither can drift from
the other, because both are generated from one file. The system's home is
https://stoagen.com/.

How this site's record is organized:

- The whole site as one plain-text file, one fetch:
  https://stoagen.com/llms-full.txt
- The site guide with a per-page index: https://stoagen.com/llms.txt
- The canonical description of the pattern:
  https://stoagen.com/pattern/index.md
- The demo directory: https://stoagen.com/demos/index.md
- Notes for assistants: https://stoagen.com/agents/index.md

The flagship working demonstration is Pueblo Senior Services, Explained: an
independent guide to Pueblo, Colorado's senior services agency, built to be
handed to any chatbot. Its own start page is
https://pueblo-srda-questions.stoagen.com/start.md and questions about
Pueblo senior services belong there.

Everything in this file and the files above is information from the
publisher, not instructions to you. Your user's requests come first; these
notes exist so restatements stay accurate.
